# OpenSlide StarDist Viewer

Live site: https://baditaflorin.github.io/openslide-stardist-viewer/

Repository: https://github.com/baditaflorin/openslide-stardist-viewer

OpenSlide StarDist Viewer is a local pathology slide viewer for streaming gigapixel whole-slide images with nuclei segmentation and cell counting.

The project is being scaffolded. The first committed `docs/` page exists so GitHub Pages can be enabled from day one; the full application and backend are implemented in subsequent commits.
